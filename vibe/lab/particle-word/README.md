# 粒子品牌开场 · 原创应用包 0.1

适用于品牌开场、作品集首屏。原生 Canvas 2D，不依赖服务器、第三方库或外部资产。

## 运行与修改

1. 解压，直接用现代浏览器打开 `index.html`；也可放在任意静态网站。
2. 输入 1–12 个字符，点击“应用文字”。拖动密度、速度、颜色，切换文字 / 圆环 / 波浪。
3. 导出 JSON 配置或静态 SVG。JSON 记录输入，源码交付在本包；没有运行时配置上传入口。
4. 在脚本头部的 `defaults` 中修改 `word`、`density`、`speed`、`color`、`mode` 后保存 HTML。将导出 JSON 的对应字段写入此处即可再次使用。
5. 只展示画布：链接加 `?embed=1`。嵌入其他项目可用 iframe，或迁移 `.stage`、对应样式、Canvas 逻辑；保留一个普通 HTML 品牌标题作为替代内容。

## 输入 → 机制 → 输出

- 输入：文字、粒子密度、聚合速度、颜色、形态、指针坐标。
- 字形：离屏 Canvas 居中排版，透明度大于 100 的像素按网格采样。
- 插值：`p += (target - p) * (1 - exp(-k * dt))`，修正刷新率差异。
- 交互：指针半径内产生局部排斥；圆环和波浪通过参数方程生成目标点。
- 输出：实时画面、可记录的输入配置、静态 SVG；SVG 不含动画。

## 性能与限制

逻辑画布 1000×560，DPR 上限 1.5；窄屏预算 1000 点，其他视口 2400 点（均为本示例预算，不是性能承诺）。离开视口、后台标签页和暂停时停止 RAF。系统减少动态时静态展示目标。字体随设备变化，无法支持 Canvas 时显示文字说明。

该示例使用二维字形，不含深度估计或真实三维点云。长中文品牌名会自动缩小，文字可读性需自行检查。若添加品牌字体、商标或其他资产，请单独确认权利。当前无通用浏览器帧率、转化率或商业收益验证，不包含定制开发及技术支持。

## 验收

- 替换为“造物社”，应用后画面与无障碍描述同时更新。
- 空白或超过 12 字符不能替换已生效画面，错误明确提示。
- 三种形态、密度、速度、颜色、暂停、重置都可操作。
- 导出 JSON 可读且包含当前生效输入；SVG 能独立打开。
- 在 375/390 宽度、系统减少动态、后台恢复与断网直接打开文件时检查。
