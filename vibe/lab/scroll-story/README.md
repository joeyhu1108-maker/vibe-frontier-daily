# 三幕滚动介绍 / Scroll Story

VIBE FRONTIER 原创应用实验 02，版本 1.0。用滚动依次讲清“整体 → 构造 → 使用场景”。适合产品介绍、作品集与项目提案。

## 打开与使用

1. 解压后直接打开 `index.html`，或用任意静态 HTTP 服务预览；不安装依赖。
2. 在右侧编辑三幕标题与正文。编辑时预览跳到对应章节；也可点预览下方 01 / 02 / 03。
3. 在预览画面里上下滚动。修改强调色、切换“作品集提案”预设，或恢复初始内容。
4. “导出我的文案 JSON”保存当前文案与强调色。该文件是配置，不能单独运行；页面暂不支持导入。重新应用时，将文字填入 `presets`，并修改强调色默认值。

页面不请求网络、不上传内容、不自动保存。刷新后恢复初始内容。ZIP 中“返回应用库”和“下载完整源码”链接用于线上网站，离线使用无需点击。

网站应用库可用 `?embed=1` 显示小尺寸实时预览：隐藏编辑器与文档，每六秒演示完整滚动机制。系统减少动态或预览离屏时停止自动推进。完整编辑页始终由用户滚动，不会自动推进。

## 输入、输出与原理

- 输入：三幕标题（各 24 字以内）、正文（各 80 字以内）、强调色、滚动进度。
- 输出：实时 SVG 构图、章节文字、进度条，以及按需导出的配置 JSON。
- 进度：`p = scrollTop / (scrollHeight - clientHeight)`，范围限制为 0–1。
- 拆解量：`spread = 1 - abs(2p - 1)`。第一幕为整体，中间展开，最后重组。
- 灯罩位移：`-76 × spread`；底座位移：`66 × spread`。单位为 SVG 视图坐标。
- 最后一幕场景由 `clamp((p - 0.55) / 0.45)` 淡入。
- 叙事文字以 `min(2, floor(p × 3))` 选择章节。章节按钮映射到 0、0.5、1。
- 无第三方框架，无 3D 模型；画面是独立编写的 SVG 构造示意。

## 替换到自己的项目

`<g id="shade">`、`core`、`base` 分别是三个运动层。保留分组和 ID，即可替换内部图形。若换成图片或真实产品素材，自己确认许可，调整位移数值与标注位置。

`presets` 保存示例文案，`draw()` 将进度映射到构图，`goToScene()` 对应章节按钮。文案经 `textContent` 输出，不作为 HTML 执行。把“整体 → 构造 → 使用”换成“问题 → 方法 → 交付”，即可形成作品集结构。

接入整页滚动时，将 `viewport` 换成页面滚动容器，并重新计算当前段落开始与结束位置；不要把本例的内部滚动距离原样当作整页距离。成交、预约、分析埋点和服务端不包含在此示例中。

## 性能、移动端与降级

- `passive` 滚动监听配合单次 `requestAnimationFrame` 排队；每帧复用相同 SVG 节点。
- 预览容器离开标签页时暂停装饰性漂浮；“暂停漂浮”按钮独立控制漂浮，用户滚动仍有效。
- 系统设置减少动态时关闭漂浮、按三幕静态构图切换。仍能编辑、滚动、导出。
- 不支持 `position: sticky` 时显示提示，改用章节按钮驱动静态构图。
- 无 `requestAnimationFrame` 时使用 16ms 定时回退；无 JavaScript 时保留第一幕静态画面及说明。
- 375px / 390px 宽度使用单列布局，预览在前、编辑在后。章节文字应保持简短。
- 未进行真实设备帧率、屏幕阅读器或跨浏览器兼容性验收；复杂图形接入后需要重新测量。

## 手动验收

1. 滚动到 0%、50%、100%，分别看到整体、展开构造、场景重组；章节高亮与进度一致。
2. 修改每幕标题和正文，预览应显示原样文字；输入 `<img onerror=...>` 不得执行 HTML。
3. 切换预设、强调色、恢复初始内容，图形标注与文字正常更新。
4. 暂停漂浮后自动漂浮停止；滚动仍由用户控制。系统减少动态下取消漂浮。
5. 导出 JSON，检查三幕文字、颜色与 `version: 1`，页面不显示虚构“上传成功”。
6. 在 375×812、390×844 和桌面检查无横向溢出；可用键盘聚焦预览并滚动、切换章节、编辑。
7. 双击 HTML 离线打开，应无外部资源请求，核心体验可运行。

开发阶段已对内联 JavaScript 执行 `node --check` 语法检查。浏览器实际视觉与交互检查以发布方的验收记录为准，不把语法通过当作实机通过。
