技术拆解 / 滚动如何变成镜头？ ＋

将滚动距离映射到 0–1 的进度，再在三幕关键位置间插值。灯罩上移、底座下移、标注淡入，最后重组到使用场景。SVG 是分组示意图；这里没有 3D 模型，也不需要 WebGL。

p = scrollTop / (scrollHeight − clientHeight)
拆解量 = 1 − |2p − 1|

滚动监听只排队一帧更新；离开页面暂停漂浮。系统减少动态时取消漂浮，并按章节切换静态构图。

拿去应用 / 从实验接到项目 ＋

替换 presets 文案与 SVG 分组，就能使用同样的滚动机制。产品页用“整体 → 构造 → 使用”，作品集用“问题 → 方法 → 交付”。先让内容顺序成立，再增加镜头。

下载包可直接打开 index.html。独立编写的示例代码与 SVG 使用 MIT 许可；灯具为虚构示意，无产品性能或商业结果承诺。
