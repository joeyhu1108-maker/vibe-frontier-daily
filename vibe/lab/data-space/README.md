# 活动数据空间 / Data → Space

一个独立编写的 SVG 应用实验：把同一单位的活动分类数据映射为等距柱图，支持编辑、选择、参数调整、导出和精确数值阅读。

## 开始使用

1. 解压后直接用现代浏览器打开 `index.html`，无需安装依赖或联网。
2. 修改右侧数据与单位，点击「生成图表」。原页面的数值是演示数据，不是实际报名或经营结果。
3. 点击柱体，或通过选择框读取完整名称和数值。图内支持方向键、Home、End；下方可展开数值表。
4. 导出 SVG 放入报告，或下载 JSON 保存当前数据与参数。

源码 ZIP 和返回应用库的链接仅在完整网站路径中可用；离线包的核心编辑、图表、SVG/JSON 导出独立可用。

## 输入格式

```csv
名称,数值
摄影,48
陶艺,36
城市漫步,71
```

- 表头可省略，或使用 `label,value`；必须是英文半角逗号分隔。
- 2–12 条记录，名称必填、不重复，最多 16 个 Unicode 字符，名称不能含逗号。
- 数值必须填写；0 合法，不接受负数、NaN、Infinity、科学计数法、带逗号的千位格式或超过 3 位小数。
- 每个值不超过 1,000,000；输入不超过 2,000 个字符。内部空行会明确报错。
- 单位 1–8 字，整张表共用。请不要将“元”和“人次”混成一张图。
- 这不是完整 RFC 4180 CSV 解析器，不支持引号转义、字段中逗号或换行。

输入错误会保留上一次有效图表，同时暂停导出，避免误把旧图当成新数据。修改输入后必须点击「生成图表」才更新图表。

## 原理与映射

```text
最大值 = max(各分类数值)
柱高 = 数值 / 最大值 × 220 × 高度比例
```

全表为 0 时，柱高为 0，并显示“暂无占比”。顶面和侧面仅是 SVG 几何装饰，立体深度不改变柱高。前、侧、顶三面由同一主色派生明暗。

适用于同一张图中的分类对比。每张图按自身最大值归一化，因此不同时间批次的两张图不能直接按视觉柱高比较。若用于跨图比较，请将最大值修改为统一的业务上限，并在页面写明尺度。

空间图有展示价值，也会产生视角干扰；精确核对请读数值表，或把「立体深度」调为 0。图表不提供转化率、增量收入、因果归因、统计显著性或预测。

## 改成自己的项目

- 修改 `SAMPLE` 可以替换初始数据；修改 `defaults` 可以更换单位、主色、高度和深度。
- 业务接入可将 API 结果映射为 `{ label, value }[]`，完成与 `parseData` 同等的校验后，赋给 `state.rows` 并调用 `render()`。
- 应用框架中应把 `state` 移入本地组件状态，在挂载后渲染，卸载时移除事件监听。
- 本页没有后端、账号或存储，不会主动上传输入。数据提供者仍需确认真实性及公开权限。

JSON 是可读配置，不是自动恢复入口。重新使用时，把 `rows` 转为 `名称,数值` 行并粘贴到输入区，填写 `unit`；`height`、`depth`、`color` 对应页面三个参数。也可在自己的项目中读取这些字段初始化状态。

## 性能与降级

- 最多 12 个分类，仅在数据、参数或选择发生变化时更新，无持续动画循环。
- SVG 为矢量输出，不需要 Canvas DPR 设置，不依赖 WebGL、GPU 特性、远程图片或字体。
- 窄屏图中文字会缩小，可使用下方选择框和数值表读取完整数据。布局适配 375px 与 390px 宽；请在实际目标设备复核。
- 没有运动效果，因此减少动态设置下也保持同样可读性。隐藏标签页没有动画或计时渲染工作。
- 依赖现代浏览器原生 SVG、Blob、Object URL 和下载能力；移动浏览器可能以预览/分享代替直接保存，以实际浏览器行为为准。

## 手动验收

1. 演示数据合计应为 366 人次，摄影为 48，城市漫步为 71。
2. 改成 `摄影,0` 和 `陶艺,0` 两条记录，应正常显示，无占比和除零错误。
3. 测试空值、负数、重复名称、NaN、科学计数法、超过 12 条、超长名称与超大数值，均应明确报错且保留旧图、禁止导出。
4. 点击/选择/键盘移动应同步选中活动及其数值；表格与图表相同。
5. 修改主色、高度和深度应实时更新；数值及占比保持不变。
6. SVG 导出后重新打开，应显示完整图形、标签与来源标记。JSON 应包含已生成数据和当前参数。
7. 在 375px、390px 与桌面视口检查，无横向溢出、遮挡或不可点击按钮。
